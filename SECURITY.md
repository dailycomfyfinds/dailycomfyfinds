# Security Policy

## Supported Versions
We currently provide security updates for the following versions of the project:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Dailycomfyfinds, please do not disclose it publicly. Instead, send an email to [comfortablefinds@gmail.com]. 

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress in addressing it.
